Run from an Excel file (.xlsx)

Reads the WO ids and the current fill color of each WO cell from your sheet (hidden/filtered rows included). Nothing is written back to the file. When the run finishes, the results page shows a "Changes vs file" report.

1. The file
Row numbers as you see them in the sheet (row 1 is the header). Leave both empty for the full list.
Choose a file to see how many WOs it contains.
